# 链上交易飞书通知脚本

该脚本定期查询 Blockscout 数据库中的 `transactions` 表。一旦发现新交易，就向配置好的飞书群机器人发送提醒。

## 快速开始

```bash
cd /www/blockscout/monitoring/tx_notifier
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

export TX_NOTIFIER_FEISHU_WEBHOOK="https://open.feishu.cn/open-apis/bot/v2/hook/xxxx"
export TX_NOTIFIER_DB_HOST="127.0.0.1"
export TX_NOTIFIER_DB_PORT="7432"
export TX_NOTIFIER_DB_NAME="blockscout"
export TX_NOTIFIER_DB_USER="blockscout"
export TX_NOTIFIER_DB_PASSWORD="********"
export TX_NOTIFIER_EXPLORER_URL="https://www.nbblocks.cc"

python tx_notifier.py
```

> **提示：** 首次启动会将状态初始化到数据库最新一笔交易，从而避免把历史交易全部发送到飞书。

## 可用环境变量

| 变量名 | 说明 | 默认值 |
|--------|------|--------|
| `TX_NOTIFIER_FEISHU_WEBHOOK` | **必填**，飞书群机器人 webhook | - |
| `TX_NOTIFIER_DB_DSN` | PostgreSQL 连接串；如果提供则覆盖下方逐项配置 | - |
| `TX_NOTIFIER_DB_HOST` | DB 主机名/IP | `localhost` |
| `TX_NOTIFIER_DB_PORT` | DB 端口 | `5432` |
| `TX_NOTIFIER_DB_NAME` | 数据库名 | `blockscout` |
| `TX_NOTIFIER_DB_USER` | 用户名 | `blockscout` |
| `TX_NOTIFIER_DB_PASSWORD` | 密码 | - |
| `TX_NOTIFIER_DB_SSLMODE` | 例如 `require`、`disable` | 未设置 |
| `TX_NOTIFIER_POLL_INTERVAL` | 轮询间隔（秒） | `5` |
| `TX_NOTIFIER_BATCH_SIZE` | 每次最多抓取交易数 | `200` |
| `TX_NOTIFIER_MIN_VALUE_WEI` | 只有金额 ≥ 该阈值才通知 | `0` |
| `TX_NOTIFIER_WATCH_ADDRESSES` | 仅监控指定地址（逗号分隔，0x 开头）；为空表示全量 | 空 |
| `TX_NOTIFIER_STATE_FILE` | 状态文件保存路径 | `tx_notifier.state.json` |
| `TX_NOTIFIER_EXPLORER_URL` | 飞书消息中的交易链接前缀 | 未设置 |
| `TX_NOTIFIER_COIN_SYMBOL` | 金额单位展示（如 `NBC`、`ETH`） | `NBC` |
| `TX_NOTIFIER_TIMEZONE` | 通知中显示的时区，例如 `Asia/Shanghai` | `Asia/Shanghai` |
| `TX_NOTIFIER_SKIP_COIN_TRANSFERS` | `true/false`，是否忽略纯原生币转账（input=0x） | `true` |
| `TX_NOTIFIER_WEBHOOK_TIMEOUT` | 请求飞书的超时时间（秒） | `5` |
| `TX_NOTIFIER_VERBOSE` | `true/false`，控制日志级别 | `false` |

## 注册为 systemd 服务

`tx-notifier.service` 示例如下，可根据实际路径调整：

```ini
[Unit]
Description=Blockscout Transaction Notifier
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/www/blockscout/monitoring/tx_notifier
EnvironmentFile=/www/blockscout/monitoring/tx_notifier/tx-notifier.env
ExecStart=/www/blockscout/monitoring/tx_notifier/.venv/bin/python tx_notifier.py
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

然后：

```bash
sudo cp tx-notifier.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now tx-notifier
sudo systemctl status tx-notifier
```

## 飞书 Webhook 调用格式

脚本使用 JSON 文本消息（含 `msg_type` 字段），否则会返回 `{"code":19002, "msg":"params error, msg_type need"}`。[官方接口示例](https://open.feishu.cn/open-apis/bot/v2/hook/d48dbe25-8ba6-4018-ad12-a13c63243c58)。

```json
{
  "msg_type": "text",
  "content": {
    "text": "[交易提醒]\n区块: 705300\nTx: 0xabc...\nFrom: 0x123...\nTo: 0x456...\nValue: 1.5 NBC\n时间: 2025-11-27 12:00:00 UTC\n链接: https://www.nbblocks.cc/tx/0xabc..."
  }
}
```
